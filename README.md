# MJG Assistech & Imports

Site de Assistência Técnica de Celulares e Venda de Novos e Seminovos.

- Troca de Tela, Bateria, Conector
- Reparo de Placa e Desbloqueio
- Venda de Celulares Novos e Seminovos
- Painel Administrativo com MySQL

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
python deploy.py
```
